## 📖 About This Repository

Welcome to my **C Programming** learning repository!

This repository documents my structured journey of learning C, from fundamental concepts to advanced topics, problem-solving and practical projects.

Each module contains organized learning notes, explanations, examples and independent practice exercises. Practical source-code programs are being added alongside the documentation as the repository develops.

The goal is to build a strong programming foundation through consistent learning, revision and hands-on practice.

---

## 🗺️ Learning Roadmap

The learning material is organized into 10 progressive modules.

| No. | Module | Description | Documentation |
|:---:|---|---|:---:|
| 01 | [📘 C Programming Basics](01-Basics/README.md) | Introduction, variables, data types, input/output and fundamentals | ✅ Guide complete |
| 02 | [📗 Operators](02-Operators/README.md) | Arithmetic, relational, logical, assignment and bitwise operators | ✅ Guide complete |
| 03 | [📙 Control Statements](03-Control-Statements/README.md) | Decision-making, selection and jump statements | ✅ Guide complete |
| 04 | [🔄 Loops](04-Loops/README.md) | Iteration using for, while, do-while and nested loops | ✅ Guide complete |
| 05 | [📚 Arrays and Strings](05-Arrays-and-Strings/README.md) | Array operations, multidimensional arrays and string manipulation | ✅ Guide complete |
| 06 | [⚙️ Functions](06-Functions/README.md) | Function declaration, arguments, return values, recursion and storage classes | ✅ Guide complete |
| 07 | 👉 Pointers | Pointer fundamentals, memory addresses and pointer operations | 🔜 Upcoming |
| 08 | 🏗️ Structures and Unions | User-defined data types and memory organization | 🔜 Upcoming |
| 09 | 📂 File Handling | Reading, writing and managing files in C | 🔜 Upcoming |
| 10 | 🚀 Mini Projects | Applying C concepts through practical projects | 🔜 Upcoming |

**Progress note:** “Guide complete” means the learning documentation for that module is written. It does not mean that all practical programs or exercises have been completed.

## 💡 Repository Guidelines

- Each completed module has its own README containing structured learning material.
- Keep source-code programs in the `programs/` folder of the relevant module as those collections are introduced.
- Use clear file names that describe the concept demonstrated.
- Keep examples readable and beginner-friendly.
- Leave practice exercises unsolved so they can be attempted independently.
- Verify code examples and internal Markdown links when updating the repository.
- Update the learning progress only when the corresponding work is actually complete.
